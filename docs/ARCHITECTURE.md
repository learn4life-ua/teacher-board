# Архітектура TeacherBoard

TeacherBoard Next побудована як модульна веб-дошка. Рукописне малювання, редаговані об'єкти, математичні модулі та геометричні інструменти розділені.

## Шари сцени

1. `background` — чистий фон, клітинка, лінії, координатний фон.
2. `drawing` — ручка, маркер, гумка.
3. `objects` — фігури, текст, зображення, графіки, координатні осі, числова пряма.
4. `tools-overlay` — лінійка, транспортир, циркуль.

Zoom застосовується до всієї сцени узгоджено.

## Основні модулі

- `src/core/` — state, storage, history, scene;
- `src/drawing/` — вільне малювання;
- `src/objects/` — object manager, shapes, text, images;
- `src/math/` — графіки функцій та математичні об'єкти;
- `src/instruments/` — геометричні інструменти.

## Правила об'єктів

Кожен об'єкт має власний id та параметри. Об'єкти підтримують вибір, переміщення, масштабування, поворот, видалення, undo/redo та збереження. Фігури, текст, зображення і графіки не випалюються в canvas.

## Геометричні інструменти

### Лінійка
- переміщення;
- поворот;
- зміна розміру;
- шкала;
- побудова редагованого відрізка вздовж робочого краю.

### Транспортир
- переміщення;
- поворот;
- масштабування;
- шкала 0–180°;
- рухома мітка кута;
- побудова двох сторін заданого кута.

### Циркуль
- переміщення;
- поворот;
- масштабування;
- окрема ручка радіуса;
- відображення значення радіуса;
- режим `Коло`;
- режим `Дуга`;
- результат створюється як окремий редагований об'єкт.

## Математичні об'єкти

### Координатні осі
Окремий SVG-об'єкт зі шкалою, числовими підписами й позначеннями x/y.

### Графік функції
Окремий об'єкт із:
- формулою;
- видимою шкалою;
- межами x/y;
- налаштовуваним кроком;
- редагуванням після побудови.

### Зображення
Зображення вставляються з файлу або буфера обміну як окремі об'єкти. Вони підтримують переміщення, масштабування, поворот і видалення.
