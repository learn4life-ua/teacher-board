# TeacherBoard Next — передрелізна перевірка

Цей чек-лист використовується перед заміною legacy `index.html` новою модульною версією.

## 1. Запуск і збереження

- [ ] `preview.html` відкривається без помилок у консолі.
- [ ] Після перезавантаження зберігаються сторінки, фон, об'єкти, штрихи та інструменти.
- [ ] Autosave не створює помилок `QuotaExceededError` на звичайній дошці.
- [ ] Перемикання сторінок не змішує їхній вміст.
- [ ] Додавання, перейменування та дублювання сторінки працюють.
- [ ] Очищення сторінки можна скасувати через undo.

## 2. Малювання

- [ ] Ручка малює без стрибків на 100%, 75%, 125% zoom.
- [ ] Маркер має напівпрозорий штрих.
- [ ] Гумка видаляє рукописний шар і не зачіпає object layer.
- [ ] Undo/redo працює після кількох штрихів.

## 3. Об'єкти

- [ ] Фігура після створення автоматично переводить дошку в режим «Вибір».
- [ ] Меню фігур закрите одразу після відкриття дошки.
- [ ] Фігури можна вибирати, переміщати, масштабувати, повертати й видаляти.
- [ ] Стрілка, координатні осі, числова пряма та таблиця x/y залишаються окремими об'єктами.
- [ ] Текст створюється, редагується та зберігається.
- [ ] Швидкі математичні символи вставляються в позицію курсора.
- [ ] Зображення вставляється з файлу.
- [ ] Зображення вставляється через Ctrl+V / paste зі скріншота.

## 4. Графіки

- [ ] `x^2` будується з видимою шкалою.
- [ ] `2*x-3`, `sin(x)`, `sqrt(x)` будуються без падіння сторінки.
- [ ] Межі x/y змінюють масштаб графіка.
- [ ] Крок шкали 0.5, 1, 2 відображається коректно.
- [ ] Вибраний графік можна оновити після побудови.
- [ ] Графік можна рухати та масштабувати як об'єкт.

## 5. Геометричні інструменти

- [ ] Лінійка рухається, повертається та змінює розмір.
- [ ] «Провести» створює відрізок точно вздовж робочого краю.
- [ ] Транспортир рухається і повертається.
- [ ] Мітка кута працює в діапазоні 0–180°.
- [ ] Побудований кут залишається редагованим.
- [ ] Циркуль рухається, повертається та змінює радіус.
- [ ] Режим «Коло» будує коло заданого радіуса.
- [ ] Режим «Дуга» будує редаговану дугу.

## 6. Zoom і координати

- [ ] Фон, canvas, об'єкти й інструменти не роз'їжджаються при zoom.
- [ ] Перетягування об'єктів коректне на 75%, 100%, 125%, 150%.
- [ ] Шкала графіка та координатних осей залишається читабельною після зміни розміру.

## 7. Legacy-міграція

- [ ] Дошка з `teacherboard.v1` переноситься у v2 автоматично.
- [ ] Старий PNG canvas зберігається як нижній заблокований image-шар.
- [ ] Старі тексти переносяться як text-об'єкти.
- [ ] Заблокований legacy raster не можна випадково рухати або видалити.
- [ ] При нестачі localStorage стара v1-копія не втрачається.

## 8. Desktop / tablet / Android

### Desktop
- [ ] Chrome/Edge: основні інструменти, клавіатурні скорочення, fullscreen.
- [ ] Верхня панель не перекриває дошку.

### Tablet
- [ ] Touch-перетягування фігур та інструментів не прокручує сторінку випадково.
- [ ] Drawer налаштувань відкривається й закривається.
- [ ] Ручки resize/rotate достатнього розміру для пальця.

### Android phone
- [ ] Ліва панель інструментів доступна повністю через вертикальний scroll.
- [ ] Верхня панель доступна через горизонтальний scroll без ламання layout.
- [ ] Drawer налаштувань працює поверх дошки.
- [ ] Меню фігур не виходить за межі екрана.

## 9. Перед merge

- [ ] GitHub Actions `Validate TeacherBoard Next` зелений.
- [ ] Немає критичних помилок у browser console.
- [ ] `preview.html` не підключає `v2.js`, `v3.js` або `fixes-*`.
- [ ] Після ручної перевірки створено окремий commit із заміною `index.html`.
- [ ] Legacy-файли видаляються тільки після перевірки опублікованої нової версії.
