# TeacherBoard Next — передрелізна перевірка

Цей чек-лист використовується перед заміною legacy `index.html` новою модульною версією.

## Контури перевірки

### Автоматично після змін

`Validate TeacherBoard Next` запускається автоматично та перевіряє:
- синтаксис JavaScript;
- import-шляхи;
- критичні модулі;
- DOM-контракт `preview.html`;
- безпечний математичний parser графіків без `Function/eval`;
- природні записи `2x`, `3(x+1)`, `πx`, десяткову кому, `×`, `÷`, степені та дозволені функції;
- унікальні SVG marker ID координатних осей;
- справжню гумку через `destination-out`;
- підключення та pointer-контракт лазера без `setPointerCapture`;
- локальні координати геометричних інструментів після повороту;
- readout транспортира після rotation;
- зміну радіуса циркуля вздовж його локальної осі.

### Вручну перед релізом

`Browser Smoke TeacherBoard Next` збережений у репозиторії, але **не запускається автоматично після кожного коміту**, щоб не створювати зайві GitHub-сповіщення. Його запускаємо вручну після стабілізації змін.

Останні успішні browser-smoke сценарії вже підтвердили:
- міграцію `teacherboard.v1` → `teacherboard.v2` у Chromium;
- rollback міграції при помилці запису v2;
- старт із закритим меню фігур та активним «Вибір»;
- фігури як `.scene-object`;
- шторку та undo/redo;
- текст і графік із числовою шкалою;
- responsive drawer;
- лінійку на desktop/tablet/Android;
- побудови лінійкою, транспортиром і циркулем;
- autosave object state;
- додавання, дублювання, перейменування та видалення сторінок на desktop/tablet;
- справжню прозору гумку на desktop;
- реальне завантаження PNG на desktop.

Автоматичні тести не замінюють короткий реальний touch-тест на фізичному пристрої.

## 1. Запуск і збереження

- [ ] `preview.html` відкривається без помилок у консолі на фізичному пристрої.
- [ ] Після перезавантаження зберігаються сторінки, фон, об'єкти, штрихи та інструменти.
- [ ] При переповненні сховища статус змінюється на «Не збережено», а не показує хибне «Збережено».
- [ ] Велике зображення стискається перед збереженням і не руйнує поточний стан.
- [ ] Перемикання сторінок не змішує їхній вміст.
- [x] Browser smoke підтвердив запис object state у `teacherboard.v2`.
- [x] Додавання/дублювання сторінки проходили browser smoke.
- [x] Перейменування/видалення сторінки перевірені на desktop/tablet browser smoke.
- [ ] Повторно прогнати Android pagebar після останнього CSS-виправлення.
- [ ] Очищення сторінки можна скасувати через undo.

## 2. Малювання

- [ ] Ручка малює без стрибків на 75%, 100%, 125%, 150% zoom.
- [ ] Маркер має напівпрозорий штрих.
- [x] Browser smoke підтвердив, що гумка прибирає alpha drawing canvas, а не малює білим.
- [ ] На grid/coords фоні візуально перевірити, що після гумки фон лишається видимим.
- [ ] Undo/redo працює після кількох штрихів.

## 3. Об'єкти

- [x] Фігура створюється як окремий object-layer елемент.
- [x] Меню фігур закрите після відкриття; стартовий інструмент — «Вибір».
- [x] Шторка є окремим об'єктом та підтримує undo/redo.
- [ ] Фігури можна пальцем вибирати, переміщати, масштабувати, повертати й видаляти.
- [ ] Стрілка, координатні осі, числова пряма й таблиця x/y залишаються окремими об'єктами.
- [x] Текст створювався у desktop/tablet/Android browser smoke.
- [ ] Швидкі математичні символи вставляються в позицію курсора.
- [ ] Зображення вставляється з файлу.
- [ ] Зображення вставляється через Ctrl+V / paste зі скріншота.
- [ ] Resize зображення зберігає пропорції.
- [ ] Лазер фізично перевірити пальцем/мишкою: точка рухається, гасне після завершення жесту й не записується на сторінку.

## 4. Графіки

- [x] `x^2` будується у browser smoke.
- [x] Числові підписи шкали та назви осей x/y присутні.
- [x] Static Validate перевіряє `x^2`, `-x^2`, `2^-2`, `2x-3`, `3(x+1)`, `πx`, `sin`, `sqrt`, `abs`, десяткову кому, `×` і `÷`.
- [x] Графічний parser не використовує `new Function` або `eval`.
- [x] Static Validate вимагає відхилення сторонніх JS-ідентифікаторів на кшталт `alert(1)`.
- [ ] Межі x/y змінюють масштаб графіка.
- [ ] Крок шкали 0.5, 1, 2 відображається коректно.
- [ ] Вибраний графік можна оновити після побудови.
- [ ] Графік можна рухати та масштабувати як об'єкт.

## 5. Геометричні інструменти

- [x] Лінійка додавалася на desktop/tablet/Android у browser smoke.
- [x] «Провести» створює редагований відрізок.

- [x] Static Validate перевіряє перехід scene→local координат при поворотах 30°/90°.
- [x] Static Validate підтверджує правильний readout 60° у повернутого транспортира.
- [x] Static Validate підтверджує, що перпендикулярний рух не змінює радіус циркуля, а рух уздовж локальної осі змінює його правильно.
- [x] Візуальна відстань голка→олівець циркуля прив'язана до фактичного `radius`.
- [x] Побудована дуга успадковує rotation циркуля.
- [ ] Лінійка рухається, повертається та змінює розмір пальцем/мишкою.
- [ ] Візуально звірити відрізок із робочим краєм повернутої лінійки.
- [ ] Транспортир рухається й повертається пальцем.
- [ ] Мітка кута фізично регулюється в діапазоні 0–180°.
- [ ] Циркуль рухається, повертається та змінює радіус пальцем.
- [ ] Візуально звірити коло/дугу з положенням голки й олівця на фізичному пристрої.
