# TeacherBoard Next — передрелізна перевірка

Цей чек-лист використовується перед заміною legacy `index.html` новою модульною версією.

## Автоматично перевірено

GitHub Actions виконує два незалежні контури перевірки:

- `Validate TeacherBoard Next` — синтаксис JavaScript, import-шляхи, критичні модулі та DOM-контракт `preview.html`;
- `Browser Smoke TeacherBoard Next` — реальний Chromium для desktop, tablet touch та Android/Pixel viewport.

Останній browser smoke успішно перевірив:
- меню фігур закрите на старті;
- створення фігури як `.scene-object`;
- створення тексту та графіка;
- відкривання responsive drawer;
- додавання лінійки;
- додавання та дублювання сторінок;
- реальне завантаження PNG на desktop;
- desktop, tablet і Android сценарії без browser console/page errors.

Автоматичні тести не замінюють короткий реальний touch-тест на фізичному пристрої.

## 1. Запуск і збереження

- [ ] `preview.html` відкривається без помилок у консолі на фізичному пристрої.
- [ ] Після перезавантаження зберігаються сторінки, фон, об'єкти, штрихи та інструменти.
- [ ] Autosave не створює помилок `QuotaExceededError` на звичайній дошці.
- [ ] Перемикання сторінок не змішує їхній вміст.
- [x] Додавання та дублювання сторінки проходять browser smoke.
- [ ] Перейменування сторінки перевірити вручну.
- [ ] Очищення сторінки можна скасувати через undo.

## 2. Малювання

- [ ] Ручка малює без стрибків на 100%, 75%, 125% zoom.
- [ ] Маркер має напівпрозорий штрих.
- [ ] Гумка видаляє рукописний шар і не зачіпає object layer.
- [ ] Undo/redo працює після кількох штрихів.

## 3. Об'єкти

- [x] Фігура створюється як окремий object-layer елемент у browser smoke.
- [x] Меню фігур закрите одразу після відкриття дошки.
- [ ] Фігури можна пальцем вибирати, переміщати, масштабувати, повертати й видаляти.
- [ ] Стрілка, координатні осі, числова пряма, таблиця x/y і шторка залишаються окремими об'єктами.
- [x] Текст створюється у desktop/tablet/Android browser smoke.
- [ ] Швидкі математичні символи вставляються в позицію курсора.
- [ ] Зображення вставляється з файлу.
- [ ] Зображення вставляється через Ctrl+V / paste зі скріншота.
- [ ] Лазер працює як тимчасовий overlay і не записується на сторінку.

## 4. Графіки

- [x] `x^2` будується в desktop/tablet/Android browser smoke.
- [ ] `2*x-3`, `sin(x)`, `sqrt(x)` перевірити вручну.
- [ ] Межі x/y змінюють масштаб графіка.
- [ ] Крок шкали 0.5, 1, 2 відображається коректно.
- [ ] Вибраний графік можна оновити після побудови.
- [ ] Графік можна рухати та масштабувати як об'єкт.

## 5. Геометричні інструменти

- [x] Лінійка додається на desktop/tablet/Android у browser smoke.
- [ ] Лінійка рухається, повертається та змінює розмір пальцем/мишкою.
- [ ] «Провести» створює відрізок точно вздовж робочого краю.
- [ ] Транспортир рухається і повертається.
- [ ] Мітка кута працює в діапазоні 0–180°.
- [ ] Побудований кут залишається редагованим.
- [ ] Циркуль рухається, повертається та змінює радіус.
- [ ] Режим «Коло» будує коло заданого радіуса.
- [ ] Режим «Дуга» будує редаговану дугу.

## 6. Zoom і координати

- [ ] Фон, canvas, об'єкти й інструменти не роз'їжджаються при zoom.
- [ ] Перетягування об'єктів коректне на 75%, 100%, 125%, 150%.
- [ ] Шкала графіка та координатних осей залишається читабельною після зміни розміру.

## 7. PNG-експорт

- [x] Browser smoke підтвердив реальну подію завантаження PNG у Chromium.
- [ ] PNG містить фон, рукописні штрихи, фігури, текст, зображення і графік.
- [ ] PNG містить видимі геометричні інструменти.
- [ ] PNG не містить рамки виділення, handles та кнопки видалення.
- [ ] Перевірити вигляд складної сторінки з кількома різними об'єктами.

## 8. Legacy-міграція

- [ ] Дошка з `teacherboard.v1` переноситься у v2 автоматично.

- [ ] Старі тексти переносяться як text-об'єкти.
