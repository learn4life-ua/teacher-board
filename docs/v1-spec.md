# TeacherBoard v1 Specification

## 1. Мета

TeacherBoard v1 — легка інтерактивна онлайн-дошка для викладачів і репетиторів, насамперед для індивідуальних занять з математики.

Проєкт працює без реєстрації та без серверної частини, розгортається на GitHub Pages і зберігає дані локально у браузері.

## 2. Основний сценарій

Користувач повинен мати змогу:

1. відкрити дошку;
2. створити або вибрати сторінку;
3. писати від руки, виділяти маркером і стирати;
4. додавати текст, зображення, математичні фігури й заготовки;
5. переміщувати й змінювати розмір редагованих об'єктів;
6. змінювати фон дошки;
7. скасовувати та повторювати дії;
8. зберегти результат локально;
9. експортувати сторінку у PNG або заняття у PDF;
10. використовувати режим демонстрації.

## 3. Інструменти v1

### Raster tools

Ці інструменти працюють безпосередньо з canvas:

- Ручка;
- Маркер;
- Гумка;
- Лазерна указка як тимчасовий візуальний інструмент без збереження.

### Editable objects

Ці елементи повинні зберігатися як окремі об'єкти:

- текст;
- вставлені зображення;
- лінія;
- стрілка;
- прямокутник;
- коло/еліпс;
- трикутник;
- прямокутний трикутник;
- паралелограм;
- трапеція;
- ромб;
- кут;
- дуга;
- шторка;
- числова пряма;
- координатні осі;
- таблиця x/y.

Редаговані об'єкти повинні підтримувати мінімум:

- вибір;
- переміщення;
- зміну розміру;
- видалення.

## 4. Математична панель

У v1 залишити:

- фони: чистий, клітинка, лінії, координатна сітка;
- швидкі символи: √, π, ±, ≠, ≤, ≥, ∞, ∠, °, ×, ÷, ≈, ², ³, ∑, ∫;
- додаткові символи: Δ, α, β, ∥, ⊥;
- заготовки: координатні осі, числова пряма, таблиця x/y.

Повноцінний редактор формул не входить до v1.

## 5. Сторінки

Потрібно підтримати:

- створення сторінки;
- перемикання;
- перейменування;
- дублювання;
- видалення, крім останньої сторінки;
- подовження сторінки вниз;
- окремий фон для кожної сторінки;
- окремий стан canvas та objects для кожної сторінки.

## 6. Undo / Redo

Undo/redo повинні працювати для всіх змін сторінки:

- raster drawing;
- background;
- text;
- objects;
- image insertion;
- object move/resize/delete;
- curtain.

Не допускається окрема історія, яка бачить лише canvas, але не objects.

## 7. Збереження

Поточні дані не повинні губитися при перезавантаженні сторінки.

Ціль для v1:

- перейти від великих PNG у localStorage до IndexedDB або іншої локальної схеми, придатної для кількох сторінок та зображень;
- передбачити міграцію даних зі старого ключа `teacherboard.v1`, якщо це можливо без ризику втрати даних.

## 8. Export

### PNG

Експорт активної сторінки повинен включати:

- фон;
- raster canvas;
- текст;
- усі editable objects.

### PDF

Експорт заняття повинен включати всі сторінки з коректною висотою.

## 9. Responsive

Обов'язкові режими:

- desktop;
- tablet;
- mobile.

Mobile не є просто зменшеним desktop layout.

Основні дії повинні залишатися доступними без zoom сторінки.

## 10. Accessibility

Ціль: WCAG 2.2 AA там, де це практично для canvas-based застосунку.

Обов'язково:

- видимий `:focus-visible`;
- `aria-label` для icon-only buttons;
- keyboard navigation для основного UI;
- touch targets приблизно 44×44 px для ключових mobile controls;
- інформація не передається лише кольором.

## 11. UI standard

TeacherBoard підпорядковується Learn4Life UX/UI Standard з репозиторію `learn4life-ua/tooling`.

Ключові вимоги:

- одна система SVG-іконок;
- без випадкових emoji/Unicode-символів як фінальних UI-іконок;
- системні design tokens;
- без зайвих карток, glow, glassmorphism і декоративного AI-slop;
- одна чітка primary action у відповідному контексті;
- функціональний motion;
- responsive як окрема композиція.

## 12. Не входить до v1

Поки не робимо:

- облікові записи;
- хмарне збереження;
- спільну роботу в реальному часі;
- відеозв'язок;
- повноцінний LaTeX-редактор;
- складну LMS-аналітику;
- шаблони уроків із серверним каталогом.

## 13. Definition of Done

TeacherBoard v1 вважається готовим, коли:

- немає `v2.js`, `v3.js`, `fixes-v*` як окремих runtime-латок;
- немає конфліктуючих CSS-шарів версій;
- є єдина модель сторінки;
- усі заявлені v1-функції працюють на desktop і mobile;
- export PNG/PDF не втрачає objects;
- autosave відновлює заняття після reload;
- критичні keyboard/focus сценарії працюють;
- немає відомих blocker/critical bugs.
