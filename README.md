# TeacherBoard

TeacherBoard — легка інтерактивна онлайн-дошка для викладачів і репетиторів.

Перший етап проєкту орієнтований на індивідуальні заняття з математики та роботу без реєстрації й без серверної частини.

## Поточна робоча версія

`index.html` поки залишається legacy-версією, щоб не ламати GitHub Pages під час перебудови.

У legacy-стеку одночасно використовуються кілька поколінь JS/CSS (`app.js`, `v2.js`, `v3.js`, `fixes-*`), тому великі виправлення перенесено в нову модульну архітектуру.

## Нова архітектура

Нова реалізація знаходиться в `src/`, а окрема сторінка для перевірки — `preview.html`.

Уже реалізовано:

- централізований state;
- versioned localStorage;
- undo/redo;
- єдиний scene zoom;
- ручку, маркер і гумку;
- object manager;
- геометричні SVG-фігури як окремі об'єкти;
- текст як редагований об'єкт;
- зображення з файлу та буфера обміну як об'єкти;
- графіки функцій із видимою шкалою, межами x/y та кроком;
- координатні осі й числову пряму;
- лінійку з побудовою відрізка вздовж краю;
- транспортир із рухомою міткою 0–180° та побудовою кута;
- циркуль з регулюванням радіуса та режимами «Коло» / «Дуга»;
- сторінки та фони;
- адаптивну панель налаштувань для телефону/планшета;
- міграцію `teacherboard.v1` → `teacherboard.v2` із захистом від переповнення localStorage;
- перенесення старого canvas-знімка як заблокованого нижнього image-шару, щоб не втратити старі записи.

Докладніше: `docs/ARCHITECTURE.md`.

## Статус

Ця перебудова ще не злита в `main`. Робочий GitHub Pages залишається на старій стабільній версії. Нова архітектура проходить перевірку в окремій гілці `agent/reorganize-teacher-board` та PR №6.

## Перед заміною index.html

- вручну перевірити `preview.html` на desktop, Android та планшеті;
- перевірити великі старі дошки після міграції;
- перевірити touch-жести для фігур та геометричних інструментів;
- провести фінальну перевірку undo/redo і збереження;
- після цього замінити legacy `index.html` і прибрати `v2`, `v3`, `fixes-*`.

Проєкт розрахований на GitHub Pages.
