# TeacherBoard

TeacherBoard — легка інтерактивна онлайн-дошка для викладачів і репетиторів.

## Поточний режим розробки

`index.html` поки залишається legacy-версією, щоб не ламати GitHub Pages. Нова модульна реалізація знаходиться в `src/`, а сторінка для перевірки — `preview.html`.

## Уже реалізовано в TeacherBoard Next

- централізований state, versioned localStorage, undo/redo;
- єдиний zoom сцени;
- ручка, маркер і гумка;
- сторінки та фони;
- фігури як SVG-об'єкти з вибором, переміщенням, масштабуванням, поворотом і видаленням;
- текст як окремий редагований об'єкт;
- зображення як окремі об'єкти з вставкою з файлу та буфера обміну;
- координатні осі зі шкалою й числова пряма;
- графіки функцій з числовою шкалою, межами x/y і налаштовуваним кроком;
- лінійка з побудовою редагованого відрізка вздовж краю;
- транспортир із рухомою міткою 0–180° та побудовою заданого кута;
- циркуль із регульованим радіусом, режимами «Коло» та «Дуга»;
- усі побудови інтегровані з undo/redo та збереженням сторінки.

Докладніше: `docs/ARCHITECTURE.md`.

## Що ще потрібно перед заміною legacy-версії

- міграція старих збережень;
- перевірка desktop/mobile preview;
- доведення адаптивності панелей;
- фінальна перевірка інструментів і GitHub Pages;
- після цього — заміна legacy `index.html` та прибирання `v2`, `v3`, `fixes-*`.

Проєкт розрахований на GitHub Pages.
