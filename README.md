# TeacherBoard

TeacherBoard — легка інтерактивна онлайн-дошка для викладачів і репетиторів.

Перший етап проєкту орієнтований на індивідуальні заняття з математики та роботу без реєстрації й без серверної частини.

## Поточна робоча версія

`index.html` поки залишається legacy-версією, щоб не ламати GitHub Pages під час перебудови.

У legacy-стеку одночасно використовуються кілька поколінь JS/CSS (`app.js`, `v2.js`, `v3.js`, `fixes-*`), тому подальші великі виправлення переносяться в нову модульну архітектуру.

## Нова архітектура

Нова реалізація знаходиться в `src/`, а окрема сторінка для перевірки — `preview.html`.

Уже винесено та реалізовано:

- централізований state;
- versioned localStorage;
- undo/redo;
- єдиний scene zoom;
- ручку і маркер;
- object manager;
- геометричні фігури як окремі SVG-об'єкти;
- вибір, переміщення, зміну розміру, поворот і видалення об'єктів;
- сторінки та фони;
- лінійку, транспортир і циркуль як окремі інтерактивні інструменти сцени;
- побудову редагованого відрізка вздовж лінійки;
- побудову кута 0–180° транспортиром;
- побудову редагованого кола циркулем;
- координатні осі зі шкалою та числову пряму як математичні об'єкти;
- графіки функцій як окремі редаговані об'єкти;
- налаштування меж x/y і кроку шкали графіка;
- підтримку простих формул: `x^2`, `2*x-3`, `sin(x)`, `sqrt(x)` та подібних.

Докладніше: `docs/ARCHITECTURE.md`.

## Статус

Ця перебудова ще не злита в `main`. Робочий GitHub Pages залишається на старій стабільній версії, а нова архітектура проходить поетапну перевірку в окремій гілці.

## Наступний етап

- текст як об'єкт;
- вставка та редагування зображень;
- точніше керування радіусом і дугою циркуля;
- додаткові математичні заготовки;
- міграція legacy-збережень;
- фінальне тестування перед заміною `index.html`.

Проєкт розрахований на GitHub Pages.
