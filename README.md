# TeacherBoard

TeacherBoard — легка інтерактивна онлайн-дошка для викладачів і репетиторів.

Перший етап проєкту орієнтований на індивідуальні заняття з математики та роботу без реєстрації й без серверної частини.

## Заплановано для v1

- сторінки на кшталт Jamboard;
- ручка, маркер і гумка;
- текст, лінії, стрілки та прості фігури;
- фони: чистий, клітинка, лінії, координатна сітка;
- математичні символи;
- вставка зображень і скріншотів із буфера;
- undo / redo;
- автозбереження у браузері;
- експорт сторінки у PNG;
- повноекранний режим;
- шторка для приховування відповіді;
- лазерна указка.

Проєкт розрахований на GitHub Pages.
