# Нова модульна структура

Ця папка призначена для поступової міграції TeacherBoard з набору версійних і patch-файлів до модульної архітектури.

Поки міграція не завершена, робоча версія продовжує використовувати файли з `js/` і `css/`. Нові модулі потрібно переносити сюди по одному, з перевіркою сумісності після кожного етапу.

Порядок перенесення: `core` → `objects` → `drawing` → `math` → `instruments` → `ui`.

Не слід видаляти старі файли до того, як нова модульна версія повністю відтворить їхню функціональність.
