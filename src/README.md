# TeacherBoard `src`

Ця папка містить нову модульну реалізацію TeacherBoard. Вона розробляється окремо від legacy-коду у `js/`.

## Поточний зріз

- `core/state.js` — єдиний стан дошки та сторінок;
- `core/storage.js` — версоване локальне збереження `teacherboard.v2`;
- `core/history.js` — undo/redo на рівні сторінки;
- `core/scene.js` — єдиний zoom усієї сцени;
- `drawing/freehand.js` — ручка, маркер і базова гумка;
- `objects/shapes.js` — SVG-геометрія;
- `objects/object-manager.js` — виділення, переміщення, масштабування, поворот і видалення об'єктів;
- `instruments/geometry-tools.js` — лінійка, транспортир і циркуль як інтерактивні інструменти верхнього шару;
- `app.js` — зв'язування UI з модулями.

Для перевірки нової архітектури створено `preview.html`. Він не підключає `js/app.js`, `v2.js`, `v3.js` або `fixes-*`.

## Уже реалізовано у preview

- фігури як окремі SVG-об'єкти;
- автоматичне повернення до режиму `Вибір` після створення фігури;
- переміщення, зміна розміру, поворот і видалення фігур;
- ручка та маркер;
- undo/redo;
- сторінки;
- фони;
- єдиний zoom для сцени;
- лінійка, транспортир і циркуль як окремі об'єкти сцени;
- збереження інструментів разом зі сторінкою.

## Наступні модулі

1. коректна гумка через сегменти/маску, а не білий колір;
2. текст та зображення як об'єкти;
3. математичні осі, числова пряма і графіки як об'єкти;
4. функція малювання вздовж краю лінійки;
5. вимірювання кута транспортиром;
6. побудова кола/дуги циркулем;
7. міграція сторінок зі старого `teacherboard.v1`;
8. після перевірки — заміна legacy-стека в `index.html`.

`main` до завершення перевірки не змінюємо.
