# Legacy

Поточна робоча версія TeacherBoard історично складається з базових файлів та послідовних доповнень `v2`, `v3`, `fixes-v5`, `fixes-v6` тощо.

На етапі реорганізації ці файли не видаляються і не переміщуються, щоб не зламати GitHub Pages. Після завершення модульної міграції стабільну стару версію можна буде перенести сюди як архівну контрольну копію.

Мета: у фінальній версії не повинно залишитися ланцюжка patch-файлів, що змінюють поведінку один одного через порядок підключення.
